## 1. 机器人强度校准：加了一个旋钮 `wander`（偏离规格）

- 规格给的调参顺序只有 topK / temp / overlook（±30 %）。只用这几个旋钮，机器人对“孩子模型 B”太强了：第一次测量（60 局）翻翻棋 1–4 号的孩子胜率只有 0.44 / 0.13 / 0.05 / 0.04。
- 所以加了 `wander`：机器人有一定概率走“新手步”。这是旧版原型里的 `randomMove`，但要先过新手硬过滤，所以不会自己走进大本营，也不会在有别的步可走时去送死。1 号机器人看起来像新手，不像坏掉了（自动检查：非被迫的大错 = 0）。
- 结果：21 个格子全部通过（`calib-2026-10-06.txt`）。有两个格子只是靠 ±0.05 的容差才算通过：
  - 暗棋 1 号（豆豆）：孩子胜率 0.755，目标区间 0.80–0.95。随机性再加大也降不下来（wander .85 时 0.73）。原因是暗棋里乱走大约和孩子模型 B 一样强。
  - 暗棋 4 号（老将）：0.147，目标区间 0.15–0.30（另一条门槛“孩子赢 ≥ 0.10”满足，实测 0.145）。
- ☑ 爸爸同意按现在的强度发布（2026-10-07）

## 2. 自对弈 600 步上限：只在“随机对随机”里出现过 1 次

- §9.3 要求“每局 600 步内结束，触顶 0 次”。3000 局里，有机器人或孩子模型参与的对局触顶 **0 次**。只有 1 局暗棋“随机对随机”触顶（`selfplay-2026-10-06.txt`）：两个完全随机的玩家可能一直不吃子。
- 触顶时的处理是对的：按 R7 清点兵力或判和。真实孩子的对局里不会出现这种情况（对手都是机器人）。测试允许随机对随机的触顶率 ≤ 1 %，有机器人参与的对局必须为 0。
- ☑ 爸爸接受这个例外（2026-10-07）

## 3. 家规“翻翻棋扛旗 = 随时能扛”现在也用于对战机器人

- 第 2 轮修复：家长面板这条设置以前只影响家庭局。现在对战（天梯）翻翻棋也照这条家规（§8.7、§9.8 第 3 条）。规则在开局时写进这局的存档，所以续局和复盘都用开局时的规则。家长面板上的说明改成了“对战和家庭局都用”。
- 注意：机器人强度是按标准规则（先挖光地雷才能扛旗）校准的。改成“随时能扛”后，孩子和机器人都更容易扛到旗，胜率会有一些变化。

## 4. 参谋提醒 / 提示的统计门槛（§9.5）：现在有了自动测试

`tools/military-chess/coach-hint.heavy.test.ts`，结果见 `coach-hint-2026-10-07.txt`。测试是孩子模型 B 对 1–2 号机器人，三种玩法各 60 局，孩子共走 13 117 步：

| 门槛 | 实测 | 要求 |
|---|---|---|
| C1 召回（明棋，走完这步对方能直接扛旗） | 91/91 = 1.0 | 1.0（至少 60 个样本） |
| 提醒触发率 | 3.26 % | < 10 % |
| 每局 C2–C5 最多 | 3 | ≤ 3 |
| 提示质量（提示步在 4 级评估里 ≥ 第 75 百分位） | 98.4 %（492/500） | ≥ 95 %，满 500 个局面 |
| 刚按提示走完就被扛旗（明明有防守） | 0 | 0 |

第 3 轮验收后补强（QA r3）：孩子模型 B 很少把旗送到对方嘴边（它自己的走法里只有 2 个 C1 样本），所以测试现在会“埋雷”：在抽样的明棋局面里，把每一步“走完对方就能扛旗”的其它走法都当正例去测，共 89 个，加上原来 2 个，91/91 全部提醒到。提示质量的抽样也改成一定凑满 500 个有效局面（以前跳过的局面不补，只有 390 个）。手工测试 `validate/coach.test.ts` 另外覆盖了正例和反例。
