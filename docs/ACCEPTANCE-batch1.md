# 第一批验收清单（爸爸用）

第一批五款都做完了：**星港搬运工**、**星晶消消乐**、**陆战棋**（10-07 下午先交，第 3–5 节），**贪吃蛇大作战**、**机关守城**（10-07 晚上做完，10-08 又各经过一到两轮独立 QA 和修复，第 6–7 节）。前三款如果已经验收过，这次只看第 2 节（大厅）和第 6–9 节；第 6–7 节里标“（10-08 新）”的是最后两轮改过的地方。
技术细节和测试数字见 [QA-REPORT-batch1.md](QA-REPORT-batch1.md)。截图集在 Mac 上：`~/kid-games-work/shots/gallery-batch1/`。

## 1. 在 iPad 上打开本地预览

1. Mac 和 iPad 连同一个 Wi-Fi。
2. 在 Mac 的终端里运行：
   ```
   cd ~/github/kid-games
   ./play.sh
   ```
   它会先按 Netlify 的方式构建（大约 1 分钟），然后打印一个地址，比如 `http://192.168.x.x:8000`。
3. iPad 打开 Safari，输入这个地址。想像孩子那样玩，可以点“分享 → 添加到主屏幕”，然后从主屏幕图标打开。
4. 验收完，在终端按 `Ctrl+C` 停掉。如果已经构建过、代码没改，可以用 `SKIP_BUILD=1 ./play.sh` 跳过构建。

注意：
- 本地预览和线上网站是两个不同的地址，所以存档互不影响。孩子线上的进度不会被动到。
- 局域网 http 下不会离线缓存。这是正常的，线上是 https，可以离线。
- 先把 iPad 音量调好；游戏有旁白和音乐。

- [ ] 竖着拿和横着拿都不用滚动，卡片排得好看。
- [ ] 火星基地、月宫建造师等还没做的游戏在大厅上看不到，这是正常的。

## 3. 星港搬运工（基地，约 15 分钟）

- [ ] 点卡片 → 点“开始” → 约 6 秒的开场动画 → 进入 0-1“第一推”。2 秒后会出现一只幽灵手，示范怎么操作。
- [ ] 点箱子：出现脚印提示和“站到这里”的语音。点地面走，点箱子推，箱子推到发射台后会锁住，然后火箭发射（第一次发射不能跳过），最后是 3 星结果卡。
- [ ] 0-3“推不回来”：故意把箱子推进墙角。看是否出现 ✕ 标记和虚线框，“撤销”按钮是否闪；点撤销能倒回去。
- [ ] 打完第 0 章：出现“第 0 章完成”卡，然后邀请参加“跳级考试”。考试里没有提示，这是规格的设计。
- [ ] 💡 提示：连按 3 次（每次间隔几秒），依次是圆圈 → 路线箭头 → 幽灵机器人示范。用过第 3 级提示的关最多 2 星，之后会推一关“镜子仓库”。
- [ ] 货运图上能切到“经典”页签（旧版 10 关）。“随机新仓库”有小/中/大三种货单。
- [ ] 横屏、竖屏都玩一关；中途转动 iPad，局面不乱。
- 看什么：画面和动画像不像商店里的正经游戏；孩子不识字能不能看懂；旁白有没有串台或重复。

## 4. 星晶消消乐（游乐场，约 15 分钟）

- [ ] 点卡片 → 开始 → 星晶号停靠的小过场 → 1-01。只有 4 个格子亮着，幽灵手示范“把两颗晶石换个位置”。
- [ ] 1-01 到 1-05：每关一个新元素（火箭、点发、无人机、星爆弹），先看介绍卡，再在这关里用。
- [ ] 连消和组合技（两个火箭交换等）有震屏、喊话、光束；收集的东西会飞到目标栏。
- [ ] 故意输一关：失败页只说“还差几个”，不责备。连输两次，领航员会说下一次帮你先装好一个道具。
- [ ] 打完第 1 站第 10 关：到站过场、选涂装、知识卡、停点卡；回到航线图，看第 2 站。
- [ ] 第 5 关以后解锁星图谜题，1-10 以后解锁“自由星海”（没有步数限制）。
- [ ] 横屏、竖屏都看航线图和一关游戏。
- 看什么：手感（拖动和点选都能换）；提示会不会来得太快或太慢（大约 10 秒后第一次提示）；字幕断行是否自然。

## 5. 陆战棋（基地，约 20 分钟；最好和孩子一起）

- [ ] 第一次打开：60 秒的无字教学（团长打营长、5 比 7 小打不过）。点 🏠 会先回营地，再点一次才回大厅（🏠 是“返回上一层”）。
- [ ] 营地四张卡：学堂 / 对战 / 残局 / 和爸爸下。残局在学完“工兵”课之前是锁着的。
- [ ] 学堂第 1 课“认军衔”做 2–3 题：答错会说为什么；💡 有三级提示。
- [ ] 对战 → 翻翻棋 → 豆豆：下一局。点 💡：如果最好的一步是翻子，那块暗子会发光，机器人说“翻开它”。
- [ ] 和爸爸下 → 明棋 → 对坐：对面的字朝向对面；悔棋需要对方同意，可以求和。
- [ ] 实体棋裁判（家里下暗棋用）：两人悄悄点各自的子，裁判只说谁被拿下。
- [ ] 家长面板：在营地长按右上角齿轮 3 秒，要输入大厅家长页设的密码。
- [ ] **请对下面 4 条打勾或批注**（详见 `content/military-chess/dad-acceptance-notes.md`）：
  - [x] 机器人强度：加了“新手步”旋钮；暗棋豆豆比目标略强，暗棋老将比目标略强一点。同意按现在的强度发布？——**同意（10-07）**
  - [x] 自对弈 600 手上限只在“随机对随机”里触顶 1 次。接受这个例外？——**接受（10-07）**
  - [x] 家规“翻翻棋扛旗 = 随时能扛”也用于对战机器人。可以吗？——**不用；对战机器人始终用标准规则（先挖光地雷才能扛旗），这条家规只用于和爸爸下（10-07 已改）**
  - [x] 残局第 3 档和更多残局题放到 v2（生成器要先改）。可以吗？——**同意（10-07）**

## 6. 贪吃蛇大作战（游乐场，约 15 分钟）

- [ ] 点卡片 → 开始 → 直接进 1-1“跟着星环”：手指按住屏幕，蛇跟着手指走。6 秒不碰屏幕，会有一只幽灵手示范。
- [ ] 1-1 → 1-2“吃星尘” → 1-3“别撞身体”，打完进大厅。大厅三块：挑战关 / 限时赛 / 无尽，还有收藏馆、纪录、设置。
- [ ] 每局开始的 3-2-1 倒计时里，能看到自己的蛇和其他蛇（上一轮修过：以前倒计时时蛇是隐形的）。
- [ ] 限时赛 → 月球场打一局（3 分钟）：被撞出局时有慢镜头出局卡，说清楚被谁、怎么撞的，然后复活；最后是领奖台，第 4 名以后讲进步，不讲名次。
- [ ] 挑战关地图：打到第 2 章（火星）。2-1 起是“出局就失败”的关——故意撞一次，看结果卡有没有说清是被谁撞的、下次怎么躲。连输 3 次会出现“先玩下一关”。
- [ ] 进入新的一章时先出故事卡，再出下一关的简报（上一轮修过：以前故事卡被盖住）。
- [ ] 提示：同一关输几次，依次出现幽灵手 → “看一招”短录像 → “领航员示范”。
- [ ] 收藏馆：皮肤、尾迹、徽章；点开一张卡会读一句知识。**请顺便看一眼这些太空知识句对不对**（规格 §9.7 要爸爸核对）。
- [ ] 设置：操控方式（跟手指 / 摇杆）、加速键在左边还是右边、比赛音乐开关。
- [ ] 无尽：一条命，可以随时“收工”，结算只出现一次。
- [ ] （10-08 新）比赛中途离开（⏸ → 回地图 → 离开），或者直接把 App 划掉：纪录里的“最长”和长度解锁（磁悬浮蛇、火车头蛇、长度徽章）都还在。以前离开会丢。
- [ ] （10-08 新）同一关输到出现“领航员示范”，看完示范后的孪生局：倒计时时会念一句“换你来，这次撞了也能接着游。”（或护盾 / 慢一点的蛇 / 大一点的星环），屏幕上有个小图标提示这次的帮忙。
- [ ] （10-08 新）3-1“截击”：金色箭头和幽灵手指向巡逻蛇**前方**要拦的位置，不再指着它的头（以前照着箭头走会一头撞上去）。结果卡上只有拿到的星星是亮的。
- [ ] 横屏、竖屏各玩一局；中途转动 iPad，比赛不乱。
- 看什么：手感（转弯是否跟手、加速是否顺）；AI 会不会太凶（孩子在月球场应该常常拿前三）；有没有一闪而过、看不懂的画面。
