# 楚河棋院试玩清单

从星港「基地」进入「楚河棋院」。手机和 iPad 都可以玩；建议先在 iPad 上与孩子同屏下棋。

1. **和家人下**：点红马，再点亮起的落点。观察棋谱和「黑方行棋」提示；可开启「轮到黑方时自动翻盘」，黑方走一步后试试悔棋。
2. **和小军师下**：先用「学徒」试一局，再切到「棋友」；分别试执红、执黑。小军师落子时棋盘暂时锁住；悔棋会退回自己上一步。
3. **残局**：八局各有唯一的一步将死解。先独立尝试，再按三次「线索」逐步查看观察方向、棋子和走法。解开后刷新，完成数应保留。
4. **换模式与返回**：已有着法时切换玩法会先确认；从返回键回大厅再进棋院，棋局应继续。

这版使用标准中国象棋规则；规则引擎、残局答案、触摸走棋、AI 回合与横竖屏布局都经过自动检查。声音在真实游玩时由游戏内落子音效提供，自动化试玩全程静音。
