# 拼音电台校准状态

尚未开始真实样本校准，保持试运行。当前日常录音数、家长抽查数、误判率、检出率、Tone.Valid 比例和评测延迟均没有可报告的实测值。

后续在正常练习中自然积累约 100 条录音，家长抽查至少 30 条。每一维分别统计：家长认为清楚却被引擎否定的比例、家长指出该维需要练习而引擎检出的比例；缺失维度单列 unsure，不填作 0 或正确。成人实验样本独立标记，不充当孩子日常样本数。

实验页可以导出三档阈值统计、p50/p90 延迟和有效声调覆盖比例。全部维度有样本、错判率不超过 10%、检出率不少于 70% 后才进入家长复核；代码不会自动切换正式模式。未过闸继续使用确定性题型和家长改判，AI 不计入掌握。

数据必须存放在仓库外。不能把录音、原始结果、家庭口令或账号信息粘进本文件。正式校准报告应只保留去标识的汇总数字、选定阈值和依据。
