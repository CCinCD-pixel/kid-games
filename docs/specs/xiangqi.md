# 楚河棋院 · v1 规格

## 玩家与定位

- 六七岁孩子与家长共用 iPad，也能在手机上玩。棋院的「小军师」是星港领航员的棋艺伙伴，语气平等，鼓励先看威胁再落子。
- 用标准中国象棋规则练观察、预测、保护与交换。不把输赢包装成考试，不倒计时。
- 中国象棋单独新增；旧国际象棋与陆战棋继续保留，不混淆规则和存档。

## v1 三种模式

| 模式 | 完成定义 |
|---|---|
| 和家人下 | 红黑双方在一台设备上轮流落子；合法落点可见；将军、将死、困毙、和棋明确提示；可悔棋、重开、翻盘。 |
| 和小军师下 | 人类可选红黑；两档儿童强度；AI 在 Worker 中只选择规则引擎给出的合法着法；思考时锁输入，可悔一回合，离开或重开时过期回复失效。 |
| 残局 | 至少 8 个经规则引擎逐条校验的残局，目标明确；错误落子可以重试，提示先给观察方向再揭示落点；完成进度本地保存。 |

## 规则和学习反馈

- 规则以 `@weshell/xiangqi.js` 为唯一合法着法和胜负来源；测试至少覆盖初始局面 perft(1/2)、马腿、象眼、炮架、将帅照面、自陷将军和各残局答案。
- 点己方棋子显示合法落点；点对方棋子或空点不改变回合；可用棋盘方向键与回车操作。
- 每次落子记录中文棋谱。小军师给短句：例如「这一步护住了车」「先看对方有没有将军」，不在对局中代替孩子下棋。
- 残局依目标判定，不只比较预设字符串；多条同样正确的着法都应通过。失败显示局面相关观察提示，无惩罚。
- 初次开局引导选模式；不要求阅读长教学。音效只走 kit，总开关/自动化静音生效。v1 可以没有音效，但字幕与视觉反馈必须完整。

## 画面与设备

- 视觉以棋盘为主，木色棋盘、红黑棋子和楚河汉界是可辨认的真实棋具，不使用表情符号代棋。
- 810×1080 与 1080×810 iPad、390×664 与 320×568 手机竖屏、844×390 手机横屏均能看见棋盘和当前回合；小屏可滚动辅助信息，但棋盘不被工具栏遮挡。
- 触点取最近交叉点，合法点、选中子、上一步、将军提示分层明确；棋盘本体尺寸不随状态变化。

## 存档与上线门槛

- `kg:v1:xiangqi` 保存模式、初始 FEN、着法列表、AI 级别、执红黑、残局完成情况。恢复时逐步重放并校验合法性；损坏存档回到安全初始局面。
- UI 端到端覆盖三模式、非法步、AI 回合、悔棋、刷新恢复、残局对错、手机/iPad 截图和控制台错误。自动化加载 `tools/qa/mute-audio.js` 且网址带 `?mute=1`。
- 规则与视觉验收完成前登记为 `hidden`；单独发布，不能带上未完成的火星基地分支。
