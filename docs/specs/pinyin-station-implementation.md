# 拼音电台实现补充约定

2026-10-22，用户本轮要求优先于 v1.0 交接中的默认约定：先交付本地可验证成品；允许本地提交，禁止 push、合入 main 或生产部署；开发和测试不得外放声音，也不改系统音量。使用独立 worktree，原主工作目录保持原状。

- 内容以拼音能力和试卷中的具体任务为主，可以补入“拼音城堡”等纯拼音材料，不要求逐页遵从人教版。当前开放第二单元范围；后续单元是数据骨架。
- 腾讯先用现有账号做本机验证，不创建子账号；已有密钥只在本机签名进程读取，不进入网页或交付包。
- 引导以鼓励和启发为主。孩子端不显示分数、红叉、批评、倒计时；三次尝试后看示范，并在后续节目再见一次。
- 家长可修改拼音、选图或保存本机图片。已有词语使用现成音频；新的多字词使用设备的中文词语语音，需家长核对多音字。单音节不使用 TTS。
- 真人音节改用许可明确的 Unlicense 音频库，o 使用独立 CC0 真人录音。许可及固定来源见 site/pinyin-station/LICENSES.part.md。
- 发音评测保持试运行，AI 不参与掌握判定。掌握基于确定性题型及家长确认，复习按会话次数安排。
- 目前可以交付 M1 本地练习版和录音/评测接入代码；M2 的腾讯真实评测、iPad 真机音频会话及 M3 校准不能用自动化测试替代。

## 平台边界

只使用 kit 公开 API。新增字体、游戏标志、依赖、Netlify 签名函数是本功能所需配套。唯一修改的平台运行逻辑是 SW 显式跳过 `/.netlify/functions/*`；netlify.toml 和 kit 实现未改。共享文档仅追加。

## 数据与隐私

试卷照片未复制到仓库或成品；本机录音和自定义图片保存在 IndexedDB，录音最多 200 条，成人实验样本另有标志。家庭口令只存 sessionStorage。关闭 AI 后不发评测请求；录音采集后在允许、联网且检测到语音时才向腾讯发出。没有任何自动重放或其他音频上传目的地。

清理浏览器站点数据会清除练习、录音和图片；家长实验页可主动导出包含语音的私有校准包，须保存在仓库外。家长 PIN 是共享设备上的操作门槛，不是加密保险箱。
