## 1. 定位、立意、能力、课标、证据
**定位**：爸爸家有一副实体国际象棋，孩子常和他下；这一作把那副棋搬进棋艺舱，iPad 与实体棋盘互相喂养（"讲给爸爸听"一句、摆棋对照卡、平放就是能悔棋 / 存局 / 让子的棋）。孩子是棋艺舱的见习棋手，领航员戴教练帽，六位机器人一位位挑战，周末和爸爸面对面。棋子保持标准 Staunton。**立意**（给爸爸看，不对孩子说教）：① 走前先看一眼（教练逐级放手、第 9 章、复盘"可改进处"）；② 赢要赢得明白（机器人从不嘲讽 / 庆祝；将死 / 逼和 / 和棋有图解，和棋写"没输"）；③ 和家人一起下（旋转、让子、可撤回的悔棋 / 和棋、家规、自动存局）；④ 一副真的棋（规则 100 % FIDE；perft + 独立实现）。
**家长页 3 个指标**：课程进度（课数 / 45、每章已会）；对局（最高赢过的机器人、近 10 盘胜 / 和 / 负、教练提醒后改走比例、小局进度、"近 5 盘估计强度"）；一步杀首次做对率（近 30 题）。**课标锚点**：一上「位置」、一下「100 以内加减」（满子力 39 分）、推理（将死是穷举）；五上数对 → 棋盘坐标。证据 C（Sala & Gobet 2016：g≈0.34 缺主动对照；2017 年分析认为无可靠远迁移）：家长页写"好玩、有文化价值、适合亲子"，不写"益智"；课程顺序与阶梯 D（设计判断 + 模拟量化）；"小局比整盘更适合 6 岁"为设计判断。

### 2.3 首 60 秒：棋盒玩具（先让孩子看见"目标"）
**0–5 s** 开始门 → 点"开始"（解锁音频）→ 深靛棋盘淡入，领航员（教练帽）升起（`s.title/hello`）· **5–20 s** 白方整副棋逐个"弹"上棋盘；孩子随便点任一棋子：合法点 + 幽灵残影 + 名字小标；最多三处"试试我"：马的弧线、象的斜线、兵一步（`tb.poke/knight/bishop/pawn`）· **20–45 s** 目标一拍：迷你残局——白车 + 王对孤王（`6k1/5ppp/8/8/8/8/8/R3K3 w`），一步将死 → 金光 + 朱砂"将死"印章；点错只弹回并说 `w.*`，4 秒无触摸幽灵手示范（`tb.goal/mate`）· **45–60 s** 一颗星飞向棋盘边缘，四扇门依次亮起，无强制路线（`s.home`）。
验收：≥8 次触摸 / 60 s、首次动子 ≤12 s、除字幕外无文字。右上 **跳过**（kit `mountSkipButton`；家长开关"跳过开场和教学"同效，查 `shouldAutoSkip()`）。**没有"下过棋吗"问答，也没有超时自动选路径**——会下棋的孩子用学堂页眉的摸底条自己决定（§4.1）。棋盒里发现过的棋子，对应走法课标"已发现"（仍可做）。

### 2.4 面对面（和爸爸下）与家规
- **布局**：iPad 平放，隔桌对坐。**黑方棋子旋转 180°**（`rotationFor(p,'f2f')`；黑子有 rot-lit 变体，光源仍在左上，§6.3），棋盘本体永不翻转。白簇（悔棋·和·认输·设置）近白；黑簇整体旋转 180° 近黑（竖屏在页眉 🏠 右侧，横屏在右面板上半）；该谁走，那侧外框亮金边 + 簇上亮灯，无倒计时。没有领航员、没有字幕，只有音效；小教练默认关，只在小步步一侧。
- **悔棋 / 和棋 / 认输**：一方点 → 另一侧弹"同意 / 先不用"卡（朝向对方）；同意生效（悔回该方上一步之前）；**发起方可「撤回请求」（`Consent.cancel()`），永不超时锁棋盘**；认输二次确认（按住 1.5 s）。
- **家规**（赛前底板"更多"；对机器人固定默认）：`{repetition:'draw'|'warn'|'off', fifty:'draw'|'off', undo:'free'|3}`，默认 draw / draw / free（FIDE 里三次重复与五十回合其实要**申请**才和，这里默认自动判；`warn` = 判和 + 第 2 次预警；`off` = 让练 KQ 对 K 的孩子不被自动判和）。常驻一行摘要「家规：自动判和 · 五十回合 · 悔棋不限 [改]」，终局卡写"按家规：…"，经 `cfg` 传 `createRules(cfg)`，Worker 同一份。"和家里实体棋的差别"卡（赛前一页 + 家长页）：自动判和 vs 要申请、无摸子走子、升变有选择框。
- **引导**（首次，≤30 s，可跳过）：平放演示 → 谁让谁（**推荐**：未赢 R3 → 让后和车；赢 R3 → 让后；赢 R5 → 让车；赢 R6 → 让马；拿满 R6 徽章 → 平下；依据 §4.4，只是起点）→ 各看各的 → 摆棋对照卡（G2 后）。

## 3. 核心循环与规则（`engines/board/games/chess/rules.ts`，原型 `rules.mjs`）

### 3.1 会话循环
**一次会话 12–15 分钟**（1–2 个课段，或 1 个小局 + 3 道题；整盘 5–25 分钟，随时存）：Bay → 一课段 / 一个小局 / 一盘 → 收尾卡（星、"今天学了什么"、`t.<章>` 讲给爸爸听一句；下一项 / 回舱 / 再来一次）。对局中随时"存 / 退出"，下次"接着下"（轮到机器人则**自动发起思考**）。无硬时长、无锁；连续玩 30 分钟后领航员只轻说一次 `s.stop`。

### 3.2 规则（FIDE，8×8，`sq = r*8 + c`，r 自上 0..7，c = a..h）与引擎契约
王不能走进被攻击的格；兵首步两格、斜吃、**升变**（后车象马，每个升变子一条 `M`）、**吃过路兵**；王车易位（王与该车没动过、中间无子、不在被将军中、经过的格不被攻击）。易位权只在 `apply` 一处更新（王走 → 两边没；任何着法的起点或终点是 a1 / h1 / a8 / h8 → 对应一侧没，含车被吃）。
**对齐 board-engine v1.1**：`RulesMeta{kingType:1, repeatN:3, clockPlies:100, clockReason:'fifty-move'}`（家规 `fifty:'off'` → null）· **`rules.status(s)` 只管局面**：`checkmate`（优先于五十回合）/ `stalemate` / `insufficient`（K 对 K、K + 单马 / 象、只剩王和同色格象）· 重复与限着归 `Game`（顺序：局面终局 → 第 3 次重复（家规 `warn` 第 2 次预警、`off` 不判）→ `fifty-move`）；5 个 `Outcome.reason` ↔ 终局说明卡键 `g.mate / stale / insuff / rep / fifty` · `hash` = 布局 + 走子方 + 易位权 + 仅当过路兵真合法时的 ep 格 · `clock(s)` = FEN halfmove · `moveInfo.resetsClock` = 吃子或兵动；`capture{sq,piece}`（过路兵 `sq≠to`；升变吃子同时有 capture 与 promotion）· `effects()`：马 `arc`；易位 = 王与车两个 `move` 同阶段（车 `arc`，≈240 ms 并行）；过路兵 / 吃子 = `capture`；升变 = `promote` · `check()` = `{king, by[]}`（闪击 / 双将的暗子也在 `by`）· `mirror()` 丢易位权（含易位权的课题用手工孪生）· `value` 1 / 3 / 3 / 5 / 9。28 项终局向量（`vectors-game.mjs`，经通用 `Game`；含"ep 不合法不拆分重复""第 100 步将死""KQ 对 K 逼和陷阱"及各 `effects`）；原 17 项仍过。机器人不提和；孩子可认输（二次确认，计一负）或"重来"（不记）。课程扩展：陨石 = `OBSTACLE`（FEN 字母 `X`）；无王局面（`check()` 恒 null）；危险格由 `sweep` 按规则现算。

### 3.3 输入、落子与"为什么不行"（共用输入层见 board-engine §5）

### 5.1 提示阶梯（H0–H3；`core/hints.ts`；灯泡键位置固定：竖屏 dock 左起第二个，横屏键组第二个）

### 5.2 教练防漏着（自有 `games/chess/coach-policy.ts`；原型 `coach.mjs` `coach-sim.mjs`）
**为什么自带策略**：引擎通用 `core/coach.ts` 没有 `missMate`、没有深度确认、不算升变增值、SEE 把过路兵当 0；评审关掉确认 + 升变后准确率从 98–100 % 掉到 93–97 %，且有"升变格被攻击 = 丢后"的假警报。所以经 `op:'custom' name:'coachTable'` 返回 `ChessCoachRow`（引擎 `CoachRow` 的超集，`reason` 多 `'missMate'|'stalemate'`）；**EQ-1** 批准后改回标准 `op:'coach'`，数据不变。
**四种提醒**（孩子拟走 m）：① `hang`：走完后对方能净赢 ≥2 分——`L(m) = 对方最好吃子的 SEE 收益 − m 吃到的子值 − 升变增值`，**比最安全着法多亏 ≥2 分**，且深度 2 + 静态搜索确认比最佳着差 ≥220 厘兵（`CONFIRM_CP`）；② `allowMate`：走完后对方有一步杀而存在不被一步杀的着法；③ `missMate`：他有一步杀而这步不是将死；④ `stalemate`（新）：走完后对方没被将军却无合法着法，而孩子明显占优（领先 ≥3 分或对方只剩王）且有别的着法避开——孩子丢掉赢棋最常见的方式（实测：k15n 整盘对 R2–R3 约 3 %、小局约 3 % 以逼和收场；评审在 KQ 对 K 的无技术局面里测到 24–29/40）。每级 `look.reasons`：R1 = missMate + stalemate（R1 从不吃子，"会被吃"是假话）；R2–R6 = 全部四种；每盘上限 `coachCap` 3 / 2 / 1 / 1 / 1 / 1，`stalemate` 另有 2 次不占额度。
**界面**：棋子悬停目标格，气泡 `c.hang`「这个子会被吃」/ `c.hang2`「那个子还在被攻击」（按 `movedIsVictim`）/ `c.mate` / `c.stale`，箭头画 `victim → attacker`；[再想想]（棋子飞回）[就这样走]（`c.go`）；**判定表在机器人落子动画开始时由 Worker 对孩子位置的所有合法着法预算**，松手查表，没算好就不提醒。教练不替孩子下棋。
**实测**（`coach-sim.mjs`：k2n / k15n × R1–R6 各 60 盘，孩子执白 / 执黑轮换，判官 = 深度 4 搜索）：R2–R6 共 2 650 次提醒，**准确率 98.5 %**（Wilson 98.0–98.9；k2n 98.2、k15n 98.7）；确认阈值 150 时 97.8 %（97.2–98.3，未达 98 %）故定 220——同一批种子调参，略乐观，§9.3 ⑧ 手标是独立检验。提醒占孩子着法 6.1 %（R1 0.8–1.6 %），每盘上限后实际显示 ≈3.7 %；静默着法里仍有 ≈14 % 是 ≥300 厘兵的更深失误（教练只防"看得见"的漏着）；判定表平均 15 ms / p95 47 ms。**评审提的圈套已堵**：判官也是搜索 → 改深度 4，`stalemate/missMate/allowMate` 由规则裁决；孩子执白、执黑；R1 单测；发布前爸爸手标 40 个局面（§9.3 ⑧）。
