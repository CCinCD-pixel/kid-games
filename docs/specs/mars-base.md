## 0. 一屏速览

- **是什么**：火星「祝融基地」的总工程师小步步，用晶体做订单（压棒、装箱、插旗、摆阵列、称重、对战领航员）；订单交对了，基地建筑一层层长出来。商业手游品质，不是练习册。
- **v1 七个区**：轨道站（数轴）、徽章站（数位/加法/减法三块牌 + 补救章）、千晶大仓（三位数）、生产线（乘法/阵列）、称重台（等式天平 + 神秘箱）、谜题舱（数字金字塔 1 节点）、火箭赛道（无限，含二档牌组）。
- **起点超前、不考试**：第 1 次 = 90 秒教插旗和放大镜 + 发射 12 颗卫星；之后每次任务的 3 个热身槽里夹着一块徽章牌的 3 题，末尾 1 张"验货单"，**答完才一起出结果**（亮 / 差一点点）。会的徽章直接亮、补救章整章跳过；不会的只从**他错的那个知识点**补；每次访问都有新东西。
- **教**估（数轴靠比例不靠读数）、算（凑整十 / 补偿 / 想加算减）、验（答错把**他的答案**演出来；领航员报错要他验收）、猜后验（转一转、拿走一样的、打开箱子）。**产品层**：一个任务运行器 + 题族注册表（oracle 判分 + 20 类误解分类）+ H0–H3 提示（关旁白也完整）+ 掌握按正确率不看速度 + 自适应（首试 75–85%，回归闸门）+ 家长页（PIN，只和自己比）。任务 6–9 分钟，停在收尾卡不自动开下一个。

## 1. 定位、立意、目标能力、课标锚点、证据等级

**1.1 定位**：他是火星「祝融基地」的总工程师——矿车运来火星晶，他按订单装棒、装箱、插旗、称重，订单交对了基地就长出新建筑。身份是总工程师，不是答题的小朋友；领航员是会出错、要他验收的副手。**超前优先**：他一年级、100 以内加减流利、有乘法概念，所以重心是 0–1000 数轴、三位数、乘法阵列、天平，一下内容只做"徽章确认 + 补救"。世界是真实航天的延伸（天问一号、祝融号 2021 年着陆乌托邦平原）。基地从不倒退。

**1.2 立意**：**数是工程师的工具：先估一估，再算一算，最后验一验。**估：插旗、赛道只标整十；算：用策略不逐个数；验：答错演示**后果**（不演出最终答案），领航员的货单要他验收。犯错是工程数据：无"错"字，伙伴从不难过。

**1.3 目标能力（家长页可见）**：A1 数轴估计趋向线性（校准 12 旗 R²≥.90、斜率 .90–1.10、PAE ≤10%/15%；**0–1000 为探索性目标**）· A2 三位数位值含 0 占位与非标准拆分 · A3 100 以内加减用策略 · A4 乘法意义、阵列、转一转 · A5 等式是"两边一样重"、未知数先拿走一样的 · A6 心算落点并验收别人的算法。

**1.4 课标与人教版锚点（以爸爸的课本为准，上线前核对）**：**用词跟教材**——数位、计数单位、个位/十位/百位、"几个十和几个一"、凑十/破十/想加算减、"大约"（二下只讲估数不教四舍五入）；孩子侧不出现"位值""交换律""四分之一"（用"数位牌""转一转""一半的一半"），"交换律"只在家长页。轨道 0–100、徽章：一下，确认 + 补救；轨道 0–1000、千晶：二下，超前 1–1.5 年；生产线：二上乘法的意义与阵列，超前 1 年，只到概念；称重台：等式，远超前，只到"天平"。**固定对应**（K1.1 与 C1.1 各讲一次并沿用）：1 根棒 = 1 个十，在十位；1 箱 = 1 个百，在百位。

**1.5 证据等级（上线前未对照原文的数字一律不写）**：**0–10 徒手数轴 / 线性棋盘 = A-（学前）**（Siegler & Ramani 2008/09 等）；**本游戏 0–1000 数轴 = B+ 外推**（有放大镜 + 微调，不是研究用的徒手估计，PAE 不能直接对任何年级常模）；文献（二手检索，原文待核）：二年级多为对数型（Siegler & Opfer 2003），四至六年级才线性，所以对他 A1 是探索性目标。课程对齐早期数学 App、位值教具与 CPA = B+/B（Kim 等元分析 g≈.31）；乘除阵列、天平/等式 = C。首试 75–85% 是调参目标，不是科学结论（Wilson 等 2019）。

### 2.2 布局（一个纯函数；六个验收视口 + 真机边距）

**`src/app/layout.ts`**：`computeLayout(viewport, safeInsets, kind) → 各区域矩形`，纯函数、Node 可测（原型 `layout.mjs`）。`kind='keypad'`（int/int2/compare2/multi/read：留键盘）或 `'folded'`（**place/build/order/open/steps 一律折叠键盘**，只留"读数 + ✓"一排，舞台增高）。所有 CSS 网格由它的输出生成（`--mb-*`），不手写第二份数字。

规则：①**kit `.kit-back` 固定 56×56 在 `(max(12,safe-left), max(12,safe-top))`**：顶栏高 56（+4 间隙），含 🏠、游戏内返回、进度点（手机横屏进左侧竖栏）、提示键、再听键；游戏样式用 `--mb-xl/--mb-yt` 覆盖 `.kit-back` 的 left/top，使注入边距时 🏠 同步移动。②区域**两两不相交**、不出 usable 矩形；舞台最小高见下表，**富余 ≥8 px**。③手机横屏：左 56 px 竖栏（🏠、返回、提示、再听）+ 左列（订单卡 48、通讯条 30、舞台）+ 右列（答案框 + 键盘 3×4，键 90×44）；折叠时右列收窄到 150，舞台变宽。④**放大镜**需要指尖上方 ≥190 px 净空：折叠舞台手机 ≥246、轨道线在舞台下沿上 52 px；V10 断言放大镜框 ⊂ 舞台∩视口、∩订单卡=∅（旗在 0、L/2、L 真拖）。⑤Playwright 的 iPhone 仿真没有 `env(safe-area-inset-*)`，V10 另跑**注入边距**：横屏 (0,47,21,47)、主屏竖屏 390×844 (47,0,34,0)、iPad (24,0,20,0)（本地变量覆盖；kit 请求 ③）。

## 3. 核心循环与规则

### 3.1 会话与任务

- **访问 `sessionIndex`**：页面打开一次算一次；距上次活动 <20 分钟沿用旧号。间隔复习与验货按访问号；切后台/锁屏**暂停**所有计时。
- **任务** = 3 个**热身槽**（§3.7）+ 节点主题题（6 / Boss 8 / 喘息 4 / 校准 12 旗，校准无热身）+（有牌待验时）验货单 1–3 题 + 孪生题（仅 H3 之后，≤2）+ S3 + S4。每区**第一次进入**，3 个热身槽换成**进场探针**（§3.4）。喘息 = 开放订单，只校验"搭的和说的一致"。主动操作超过 15 分钟，当前题交付后领航员问一次"这批货先交了吧？"（两个等大按钮）。
- `planMission(save, nodeId, sessionIndex)` 纯函数，输出完整 `Item[]`（**参数存档，不靠重新生成**）；**去重按事实（参数集）不按问法**；种子 `createRng('mars-base:'+salt+':'+sessionIndex+':'+missionCount)`，`salt` 每次安装随机、存档里、**重置存档也保留**，`?test=1` 下为 0。节点旋钮之后事实数 ≥3×该条题数（V1）。

### 3.2 一道题的状态机（`app/itemMachine.ts`，纯函数 `transition(state,event,mode)`；原型 `machine.mjs` + `machine-check.mjs` 穷举 9 层事件序列）

```
normal: ANSWERING ─提交(空)→ 轻摇不计 ─提交(对)→ DELIVER（首试 = 第1次提交且 hint=0）
  miss#1 → hint=H1：CONSEQUENCE（对质 + 只演机制，停在最终数值之前）→ 重试
  miss#2 → hint=H2：预填一半（不给答案）
  miss#3 → hint=H3：幽灵手完整示范，答案出现在显示框并锁定；点 ✓ = DELIVER(assisted) → 孪生题
  提示键：未"动手"(无舞台操作且无提交) → 中性"先试试看，我在这"；首次 H1；H1→H2 需 ≥1 次提交；H2→H3 需 ≥2 次提交
cert | probe | calib: 提交任何非空 → DELIVER（只记对错，中性"收到"；无演示、无重试、无提示；答完统一出结果）；提示键 = 中性一句 `mars.cert.alone`
任何模式：空闲 45 s（`tuning`）→ 只出 `mars.hint.idle` + 提示键微光，不是提示、不计、不升级；切后台暂停并重置计时
```

- **首试正确** = 第 1 次提交对且没用过任何提示（H1/H2/H3、键触发都算）。只有首试对/错计入档位、掌握与带宽；`assisted`、热身、探针、验货、校准**不计入**首试带宽（V4 分母 = 主题题）。
- **模式** `build-first`（必须动手）：①节点有 `newElement` 且是前 2 道主题；②L1 或表征被降到 C；③同标签上一题首试错**且属误解类**（noCarry/pvConcat/zeroOmit/unitAsOne/canonicalOnly/smallerFromLarger；offByOne/other 直接重试）；④"讲给爸爸听"（每节点 ≤1）；⑤B2.1 前 3 题。其余 `answer-first`。
- **CONSEQUENCE = 对质 + 机制**：先"对质"（他的答案 vs 订单，差在哪），再演机制并**停在最终数值之前**（noCarry 停在"多出 1 根棒，现在几根？"；数轴跳跃停在最后一跳前）；**最终数值只在 H3 出现**。分类 `confidence` 低（两类同一错答、或 off-by 类）→ 只放对质。无"错"字、无红色，柔和木质"咚"；2–4 s，**点屏幕可跳过**，同任务同类第 2 次起 1.2 s。
- **最多 4 次操作有出路**（错→H1、错→H2、错或按键→H3、✓）。不重试：数轴、开放题、验货/探针/校准（`retryMode` 是**模式**属性）；place 容差内 exact 交付；close（≤2·tol）交付但不计首试、不演示、不降档；far → 虚影旗 + 距离条 → 交付、不计首试、降 1 档 → 孪生题。
- 交付动画 = 每区一个"产物时刻"（`deliverFx`）：千晶箱入舱、生产线阵列板滑上传送带并点亮太阳能一格、称重箱盖打开、数轴卫星沿轨道飞、金字塔塔尖亮灯；订单箱飞向建筑 700 ms 保留。连对音阶 `chime`（≤8 级）**答错只降 1 级**。**语音节奏**：只在任务第 1 次首试对、连对 3 与 6、用对策略（先凑成整十再改回来、往上数、转一转、拆开再算）时说一句。

### 3.3 判分与误解分类（oracle judge，模型内纯函数；UI 不判分）

整数：与 `oracle` 完全相等，≤4 位无前导 0 · `compare2`：符号对**且**点出决定大小的位 · `place`：\|落点−目标\|≤tol exact，≤2·tol close，否则 far（校准恒 exact）· `read`：\|答−真值\|≤tol · `build`：托盘总值 = 目标且合交付规范 · `multi`/`order`/`open`：按规则逐项 · `choose`：模型选择（≥3 个选项，干扰项取自该族误解类，不单独构成一题的全部作答）· 空：`empty`。`Verdict = {ok, grade, diag, confidence, empty}`。**猜中率**：每族声明 `guessP`（compare2 1/6–1/9；`equalCheck` 第一步 50%；`removeBoth` 判"还平吗"50%；`addBoth` 点虚影 33%）；**`guessP>0.15` 的第一步不单独计首试，必须带第二步**（写 □×□ / 拿走后剩几）。

**20 类**：`noCarry countOnInclusive smallerFromLarger digitReversal pvConcat zeroOmit canonicalOnly unitAsOne mulAsAdd equalAsOperator keywordOp extraZero offByOne offByTen offByStep opReversed` + 新增 **`partialDistribute`**（6×4=5×4+1）、**`cmpWrongDigit`**（比大小看错位）、**`logCompress`**（大数偏小，由校准拟合 R²_log>R²_lin 产出，用于选 H2 锚点）+ `other`。`classify` 按族 `diag[]` 优先级比较 `bug(p)===resp`（碰撞前者赢、后者只放对质），再 off-by，最后 `other`，返回 `confidence`。家长页同类 ≥2 次才计入，单次标"疑似"。

### 3.4 难度档位、自适应、直达、进场探针（`app/tuning.ts` 集中全部常数）

| 档 | 数的范围 | 表征 | 数轴 |
|---|---|---|---|
| L1 | band 1 | C 实物（必须搭）| 最宽容差 |
| L2 / L3 | band 1 / 2 | P 图示 | 新标签起始：先修已掌握 → L3，否则 L2；**近期首试 <70% 的弱学习者起 L1** |
| L4 / L5 | band 2（有 3 档的用 band 3 一半概率）/ 最高 band | A 符号 | 容差收紧 |
| L6 | 该族**挑战变体**（§4.4 `l6` 规则）| A | 最窄容差 |

- **档位只改表征（和数轴容差），不改节点给的 band**；Boss 每族 2 题打乱、同族不相邻。
- **阶梯按标签（31 个标签）**：首试对连对 +1，连对 3 升 1 档；首试错降 1 档、清零；连对与档位**按标签存档、跨任务累计**；同标签连续 2 次首试错 → 接下来 3 题表征降一级。`LEVEL_OFF = [−.35, −.2, 0, +.2, +.35, +.6]`（L1…L6；v2.0 为 −.2/−.1/0/+.1/+.2/+.3）。
- **过渡**：任务末首试 <60% → 节点不前进，下次档位上限 L3、前 2 题强制动手；过渡后无条件完成 → 一个节点最多玩 2 次。
- **直达**：任务结束档位 ≥L5 且首试 ≥5/6，或同区连续 2 个任务 ≥95% → 直达卡（两个等大按钮）；选直达 → 后面 **1 个**非 Boss 节点标"跳过（可玩）"，其标签进热身探针队列（探针错 → 该节点重新被推荐）。
- **进场探针**：每区首次进入，任务的 3 个热身槽换成 3 道 A 表征探针（**延迟反馈**，不计首试；首次出现的新元素播一次幽灵手）。只决定起点，**不设任务数闸门、不依赖徽章**：

| 区 | 3 道探针 | 3/3 | 2/3 | ≤1/3 |
|---|---|---|---|---|
| 生产线 | `mul.groups` b2；`mul.groups` ask:count（"20 颗每舱 5 颗，几舱"，**不用乘号**）；`mul.skip` b2 | 跳过 P1.1、P1.3 → P1.4（乘号）| 跳过 P1.1 | P1.1 |
| 称重台 | `bal.equal` b2；`removeBoth`；`addBoth` | 跳过 B1.1–B1.3 → B1.4 | 跳过 B1.1–B1.2 | B1.1 |
| 千晶 | `pv2.read` b2；`pv3.pack`；`pv3.read` b1 | 跳过 K1.1–K1.2 → K1.3 | 跳过 K1.1 | K1.1 |

- **调参旋钮**（不改"3 对升 / 1 错降"）：偏高 → 加高 L4/L5 偏移；偏低 → 低档偏移更宽、弱学习者起 L1、过渡阈值 65%。按标签阶梯后 L6 几乎不可达，对带宽无影响；带宽是**回归闸门**。

### 3.5 掌握与间隔复习

标签掌握 = 最近 `min(10,n)` 次首试 ≥80% 对（**n ≥ 6 才判**）且最后 3 题没用提示；**不看速度**。掌握于访问 s → s+1、s+3、s+6、s+10 各 1 道热身复习（档位 −1，最低 L3）；复习首试错 → `shaky`、复习表重排为"下次、再隔 2 次"，连对 2 道解除。孩子看不到"掌握"二字，掌握不影响解锁；家长页有标签掌握地图。

### 3.6 徽章验货（认证嵌入；`app/cert.ts`；原型 `cert-sim.mjs`）

**孩子看到的**：热身槽里夹着几道"数位/加法/减法"小题（和别的热身一模一样），任务末尾一张"验货单"；答完一起出结果——**徽章亮了**，或**徽章亮一半 + 领航员"差一点点，练一单"**。从不出现"认证""考试""没通过""失败""停""墙"，没有逐题对错、没有"你的答案"演示、没有早停、没有"自己来"之类的规则句。

1. **嵌入**：每块牌 4 题 = 本次任务的 3 个热身槽（一档 a、二档 a、一档 b）+ 末尾验货单 1 题（二档 b）。C1→C2→C3 依次排在访问 2/3/4（玩得少则顺延；在徽章墙主动验则一次验完）。全部 A 表征、一次作答、`mode=cert`。**4 个答案全保存**（起点映射用全部）。
2. **规则**：4 题全对 → 亮；**恰错 1 题** → 验货单扩成 3 件（"再验两件货"，追加 2 道二档题）全对才亮；错 ≥2 → 半亮。
3. **亮**：徽章灯亮、整章补救节点标"跳过（可玩）"、部件一次升起；进入**暂定期**：之后 4 道二档题进热身（各牌合计每次 ≤2），错 ≥2 → **只**重开错题对应的 1 个补救节点（标"可玩"，不进推荐、不改地图外观、徽章不收回；家长页标"复习中"）。
4. **半亮**：`mars.cert.half.N`；徽章站建筑推荐闪光；**起点 = 错题所对应的最早补救节点**（用全部作答），之前节点标跳过可玩；练完该章 Boss（或满 3 个补救任务）后，之后的热身槽自动带 4 道复验题（新参数），亮则收尾；也可在徽章墙主动再验。

|---|---|---|---|

### 3.8 各区专属规则

#### 3.8.1 数轴——**不泄露读数，也不给计数通道**（评审 F1）

- **曝光不变量**：数轴子树的**文本、全部属性（除几何白名单）、伪元素 `content`、`<title>/<desc>`** 里的数字（阿拉伯、全角、汉字数字）只允许是 ①题目给定/H2 临时出现的**锚点标签** ②区间模式两端；**与旗位无关**。白名单 = `x y x1 x2 y1 y2 cx cy r rx ry d points transform viewBox width height style fill stroke opacity role`（**`class`/`id` 不豁免**，名字里不许带数字）。放大镜**只有刻度线**；无 `<input type=range>`、**无 `aria-valuenow/min/max`**，`role="img"` + `aria-label="数轴，把旗插在轨道上"`（位置无关）；◀▶ 的 label="往左挪/往右挪"。**提交后**反馈子树（`data-phase="feedback"`）允许数字，**且只能**出现在那里。
- **视图是纯函数** `renderNumberLine(state): string`（DOM 只是薄绑定）：泄露闸门因此能在 vitest（node，无 DOM 库）对每个状态 × 每个旗位收集 `exposedNumerals(markup, css)`（V6）。
- **交互**：按下旗（或轨道任意处）→ 旗跟手，旗尖在指尖上方 28 px；放大镜 ⌀120、×4，在指尖上方 120–140 px（净空 §2.2），**L=100 画 1 单位微刻度，L=1000 画 10/50/100 三级**（相邻微刻度 ≥6 px，358 px 断言）；抬手吸附整数；旗留轨道上可再拖，**点 ✓ 才提交**。**◀▶：L=100 步长 ±1，L=1000 步长 ±10；每次放置最多 3 次（再拖后重置）；无连发；无刻度音**；物理键盘 ←→ 同样受限。
- **校准节点（O1.0 / O1.4 / O2.6）= 空白轨道**：只有两端标签，**无刻度（除两端）、无放大镜、无 ◀▶、无刻度音**（手指精度已足够：0–100 约 3.6 px/单位；0–1000 通过线本就是 15%）。V6 的"数微调次数""数刻度"机器人在校准控件上通过率 ≤1%。提交只播"卫星入轨"，无容差带、无对错；12 旗后展示"你的轨道"。
- **容差 = 数轴的难度杠杆**（`tuning.ts NL_TOL`，%L，按档 L1…L6；`every10/every100` = 每 L/10 标数，`half` = 0/中/尾，`ends` = 只两端）：

| 标注 | L1 | L2 | L3 | L4 | L5 | L6 |
|---|---|---|---|---|---|---|
| every10 / every100 | 4.5 | 3.8 | 3.0 | 2.4 | 1.9 | 1.6 |
| half | 8.0 | 6.7 | 5.5 | 4.5 | 3.9 | 3.5 |
| ends | 10.0 | 8.5 | 7.0 | 5.5 | 4.7 | 4.0 |

  **噪声模型**（`numline-model.mjs`，V4 与 V6(g) 共用，是假设）：孩子空白轨道精度 σ（误差 SD，占 L；PAE≈0.8σ），靠近有标数的锚点更准：`sd = σ·L·g(d/L)`，`g(x)=clamp(.30+2.8x, .30, 1)`，d = 到最近标数锚点的距离。**V6(g)**（按节点配置 + 真靶点抽样）：入口档 L3，σ=6% 首试 ∈[.70,.90]（实测 80–87%）、σ=9% ≥.50（61–69%）；顶档 L6，σ=3% ≤.95（84–94%）、σ=6% ≥.50（52–69%）；底档 L1，σ=12%（刚过校准线）≥.60（67–72%）。**`expectedFirstTry` 由 (g) 导出**（σ=6%、L3、取 .05），不再手填。ends/half 节点中 close 不演示、不重试、不降档。V4 的逻辑斯蒂学习者**不适用于数轴区**，数轴首试以 V6(g) 为准。
- **反馈**：普通题**提交后才**出现容差带、目标虚影旗、距离条与"差 d"。`read`：旗由系统放好，键盘作答。`zoom`（O2.5）：点开 10 段之一（手机 5×2）→ 放大成 0–100 刻度条插旗 → 点开含目标的十段 ±0。

- **对旧实现的改动**：`sub.thinkAdd` 加 band 2；`mul.groups` b1 n∈{2,3,5,10}、b2 n∈{3,4,6}（k2–7）、b3 k3–9；`mul.array` b1 列 2–6；`bal.box1` 加 diag；keywordOp 两个方向；新族 `puz.pyramid`；`add.tens/sub.tens` b1 只在 C?.1 当入口；验货与补救用同一注册表。

### 5.2 失败处理与星级

无生命、计时、Game Over。答错 → H1 + 对质演示 → 重试；再错 H2；再错 H3 + 答案 + 孪生；**不跳题、不扣分、总能走完**；连续 2 次首试错 → 表征降一级；任何时刻一键撤销/重来；造好的建筑、星、卡永远不会被拿走。无"错"字；状态 = 颜色 + 形状（对 = 青绿 + 对勾；没对 = 琥珀 + 虚线描边轻摇；不用红色）。**星只和完成/H3 挂钩**（H1/H2 不扣星，不惩罚求助）：普通 1★ 完成 / 2★ 没用 H3 / 3★ 没用 H3 且首试 ≥5/6；Boss 完成 / 没用 H3 / 没用 H3 且首试 ≥7/8；校准**不显示星**，只给"你的轨道"；喘息完成即 3★。解锁只需 1★；无"再玩一次拿满星"文案。
