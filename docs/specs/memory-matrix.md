## 0. 速览与范围
- **是什么**：孩子是**星图记忆站的观测员小步步**；领航员说"流星雨把星图弄乱了"，每晚一次"夜航"（6 回合，约 2–3 分钟）帮它复原。四个星区（孩子看到的名字）：**记星星**（静态图案）、**追流星**（顺序，先顺着再倒着）、**送回家**（谁住在哪一间，访客捣乱）、**照镜子**（镜子立在中间，点出星星的影子）。家长页用长名：星座复刻 / 流星轨迹 / 星球住户 / 镜像。
- **自适应**：每星区 D1–D15；**连续 4 回合一次过升 1 档、1 回合没过降 1 档**（Levitt 4 升 1 降，稳态约 84%，贴近 Wilson 等 2019 的最优约 85%）；第 5/10/15 档有**星门**（独立事件、序贯检验）。**没有计时、速度分、连签、货币、失败惩罚。**
- **每回合新生成**；答不出来就**先亮答案、再换新夜空**；**一次**"再看一眼"免费（算任务的一部分），第二次起算"带帮助"。
- **成长**：28 张天文知识卡 + 旧存档"元老卡"，按**夜航数配速**（强孩子每周 ≈4 张）；每张卡点亮**星墙**一颗星，卡数到 7/14/21/28 星图站长出新建筑，每过一道星门仪器多一圈光（§8）。
- **诚实**：是"好玩的空间/顺序/方位练习"，**不是"提升智力"**（§1）。

## 1. 立意、能力、课标、证据
**立意**：只有"看一眼就记住"的观测员能把被流星雨撕乱的星图复原；复原的星图连成真的星座与行星知识卡，星图站也一点点长大。难度贴着他的水平（约五次对四次），做不到就先看答案、再换新题，不催不吓不攀比；旧星星变成一张"元老卡"，不变成关卡。
**目标能力**（家长页可见）：①视觉空间图案广度（成团与散点分开记）；②顺序记忆与倒序（倒序要"操作"，明显超前）；③物体—位置绑定（"谁在哪"，拒绝混搭访客）；④**沿对称轴镜像**（先看着照，再记着照）；⑤策略意识（成组、小声说位置、描路线、颜色+样子一起记）。
**课标锚点**（以爸爸手里的目录为准）：一上「位置」（上下左右）。**轴对称**：二下「图形的运动（一）」认识轴对称图形与对称轴（一份网络导图笔记一致）；本游戏要"在方格里摆出对称位置"，比"认识"更进一步，方格纸上画对称图形我印象在四下「图形的运动（二）」，**两份网络来源的编排互相矛盾，没能核实**——综合**超前约 1–2 学年**。**绕点转 90°**：印象在五下「图形的运动（三）」，**没能核实**；二下只"认识"旋转现象；远超一年级，所以只做挑战档。**请爸爸对照课本目录确认这两处**；镜像若比想象的更超前，照镜子的开启会收紧（§4 探针）。知识句：科学启蒙，无课标。
**证据**：图案/顺序记忆本身 **近迁移 B−、远迁移 D**（Melby-Lervåg & Hulme 2013；Sala & Gobet 2020），**所以不写"提升记忆力/智力"**；空间变换 **C+**（Uttal 等 2013；Cheng & Mix 2014 只当"有希望"；本游戏形式未验证）；自适应：4 升 1 降约 84%（Levitt 1971），最优错误率约 15%（Wilson 等 2019）。**家长页固定文案**：「练习：看一眼记住、顺序与倒序、谁在哪、镜像。这些练习主要让孩子更擅长这类任务和相关的词汇与策略；没有可靠证据表明它能提高一般智力或成绩。难度自动调到约 8 成一次做对。」不出现 IQ、"开发大脑"、"提升专注力"；不给年龄常模。

## 3. 回合规则
### 3.1 通用循环（状态机 `ready → show → fog → recall → judge → (pass | neutral | miss) → reveal → result`）
- **展示**：固定时长，**没有倒计时数字或进度环**，星光自然淡出，云雾（0.6 s）盖上；静态展示 ≥3.0 s（硬下限 2.0 s，校验器检查）；流星每颗 700 ms 亮 + 300 ms 间隔。**展示和云雾期间不播语音**（§9.4）。
- **作答没有时限**。20 s 没动静：**板面**暗星位轻轻呼吸（H0，不是再看按钮）；60 s：领航员说一次 `fb.hint0`。不扣、不催。
- **小星灯＝回合内的容错预算**（行数据 `budget`；灯数 = 预算+1：多数档 2 盏，送回家 n=3 的档 1 盏）。点偏暗 1 盏（木质"咚"、琥珀雾团，**不抖屏、不用红色、不显示"错"字**），**超过预算**则回合结束。**这是回合内容错，不是跨回合的"生命"**，没有血条和 game over（对 DoD 5 的明确说明）。结束时**不硬切**：剩下的答案由领航员**一颗颗亮起来**，结果记 `miss`。同一格重复点忽略。
- **再看一眼（全游戏唯一的规则）**：**第一次点按之前**可点一次，**免费**——任务本来就是"最多看两眼"，结果仍是 `pass`（带 `rw` 标记，只在**首次点亮该档**时少 1★）。**第二次再看、或点按之后再看**＝`neutral`（阶梯不动）。没有"连续 neutral 降档"，也没有劝人"别看第二遍"：阶梯自己停在孩子的"两眼容量"上。**星门里**同样有免费的第一眼，但没有提示/演示/看答案；**第二眼在星门里被锁**（v1.2）：按钮变灰、点它只说一次 `mm.g.nohint`，所以星门里不会再有「悄悄算没过」的 neutral；回合结束后星门小圆点如实显示这一局（金＝过、琥珀＝没过），不再停在旧状态。
- **结果分类**（`controller.classify()` 是唯一实现；输入 slips、budget、rwPre、rwMid、hint、showAnswer）：`pass`＝预算内通过、至多 1 次免费一眼、没用提示；`neutral`＝通过但用了第 2 眼 / 点按后再看 / 灯泡或演示；`miss`＝超预算或点了"看答案"（第 1 次点偏后出现，不计入有效夜航，§4）。
- **揭示（miss）**：先放一遍正确答案（亮星连线 / 流星带编号重飞 / 外星人跳回家 / 影子飞过镜面），孩子的选择叠在上面（绿＝对，琥珀圈＝多点，虚线圈＝漏掉）；主按钮「换一片新夜空」，次按钮「换个星区」。种子 `hash(安装盐:星区:档:回合序号)`；生成**永不抛错**（§6）。
### 3.2–3.4 三个旧星区
- **记星星**：4×4/5×5/6×6 观测窗，n 颗星亮起，云雾盖上后点出星位，通过后连成"星座"；k＝**8 邻域连通块数**（k=1 一整块，k=n 散点）。
- **追流星**：夜空 m 颗星（6–9），间距 ≥0.2 板边；流星依次飞过 L 颗，轨迹不留下；点对一颗画一段细线。倒着追有横幅「倒着追」+向左箭头，**换规则后的第一回合要点一下横幅才开始**（两个机翼，§4）。
- **送回家**：r×c 间房子；屋顶打开，n 位外星人（6 形 × 6 色，**形状和颜色都编码**）各住一间；屋顶合上，访客台滑出 n 位住户 + 0–4 位访客（混搭＝住户的特征重新搭配，陌生＝没见过）；点一位再点一间（或拖）；放错摇回台上，访客放哪都弹回（也算点偏）。n=3 的档只有 1 盏灯，热区 ≥56 px，点选与拖动双通道。
### 3.5 照镜子（s4，v1 只教镜像）
**一块方形观测窗**，中间一条**镜面**（§2.2）。**轴牌**每回合显示在板上方：图标（竖/横镜面）+ 文字「左右镜像」或「上下镜像」。星星只出现在镜面一侧（随机：左/右或上/下），孩子在**另一侧**点出它们的**影子**——**离镜面多远，影子就多远**。点对一颗画一条垂直于镜面的虚线连起（淡出）；点原半盘忽略。
- `看着照`翼（D1–D10）：原半盘一直亮；`记着照`翼（D11–D15）：原半盘展示 3.0–3.9 s 后被云雾盖住（镜面仍在）。
- **诊断**：生成器保证 4 种答案互不相同——影子（对）、**搬过去**（平移不翻）、**翻错方向**、**转半圈**；孩子的点正好等于某种错答案时才播 `s4.copy` / `s4.flip`，否则只是普通点偏。
- **引导回合（概念准备）**：每种轴的前 3 回合是引导——影子的幽灵位置第 1 回合 100%、第 2 回合 50%、第 3 回合 0%（描影子），**不进阶梯**。**v1.2**：这一轴的引导里**一次都没点偏、没再看、没用提示**时，第 2 个引导（幽灵 ≤50%）做完就算引导结束；**第二种轴**（上下）只要 1 个干净的引导；放置阶梯的跳级不会越过「引入一种还没引导完的轴」的那一档（落在那一档上，在那里做引导）。结果：干净的孩子第一夜是 引导·引导·真·引导·真·真（≤3 个引导，v1.1 是 6 个里 5 个）；点偏过的孩子仍走完整的 3 个。演示（H3）：星星一颗颗"翻过"镜面（0.7 s/颗）落成影子，就在这块板上。镜面只管一种变换；转 90° 见 §5.5。
### 3.6 边界情况（都要实现并测）
展示中转屏：重排、展示不重计；展示中点板面忽略；同格 150 ms 内只算一次、二指忽略；旁白缺失：字幕 + 浏览器语音；静音：反馈都有视觉；存储被禁：内存存档并提示家长；星门中途离开：整道重来。
**离开与回来**（🏠、切后台、关页面同一套规则；v1 不弹"继续上一张星图？"）：同种子同题。**实现（v1.2）**：开夜航前先存星区快照；离开时若这一夜**还没有任何一回合/星门结束**，存档就写成"这一夜从没开始过"（夜航数、机翼翻转、`swaps`、同一道题的种子都不变——v1.1 每次来回会翻一次机翼、多算一夜）；若已结束 ≥1 回合，存档带 `nightRec`（已结束回合、本夜新卡），下次开夜航**接着这一夜**（同一机翼、同一计数）；离开在雾/作答里＝**一次再看一眼且累加**（`carryRw` 每次 +1，所以多次来回会变 neutral），在 `ready/show` 里免费；回合内的「星图站」按钮和 🏠 同一规则（v1.1 它是免费的第二眼）。离开时在 `ready / show` → 重新展示，**免费**；在 `fog / recall`（含已点几颗）→ 回合从展示重来、已点丢弃，这次回放算**一次再看一眼**（免费那次没用过则仍是 pass，否则 neutral）；结果条/揭示 → 结果已记。所以"退出再进来"不是免费的第二眼，误点 🏠 也不改写测量。**测试模式** `?test=1&seed=…&sector=…&D=…`：存档在内存、角上显示 TEST 彩带，vitest 断言会话后 `localStorage` 不变。
## 4. 自适应引擎（`controller.mjs` 是规范，TS 必须过 `selftest` 的 C 项与 `controller-traces.json`）
输入只有**每回合首次作答的结果**（pass / neutral / miss，由 `classify` 给出），**不读任何时间量**。星门停止规则与资格、选翼、推荐星区**只在控制器里**（`gateStep` / `nextRound` / `startNight` / `recommend`），页面和模拟都调用它们。

| 规则 | 内容 |
|---|---|
| 升降 | 连续 **4** 个 pass → L+1（上限＝下一道未开的星门档）；1 个 miss → L−1（最低 1）；neutral 不动 |
| 放置 | 每个星区（机翼）前 8 回合，pass 直接升 3/3/3/2/2/2/2/2 档，遇第一个 miss 结束；首次起点：记星星 D3、其余 D2 |
| 轻松 / 扶一把 | 连续 2 个 miss → 一个 L−1 的轻松回合；连续 3 个 miss → 这次降 **2 档**，再来**演示回合**（领航员演示，不是测量）和**扶一把回合**（第一个答案项白送，通过算 neutral），`fb.break` 建议换星区；扶一把也没过 → 再降 2 档再演示 |
| 夜内放松 | 同一夜已有 2 次没过 → 这夜剩下的回合低 1 档（不改 L） |
| 软回合 | 换星区/机翼后的**第一回合**：没过算 neutral（L 不动，仍计入"连续没过"）；先点规则横幅才开始 |
| 星门资格 | **回合之间**邀请（v1.2：不再只在夜航开头；夜里已有 2 次没过则不邀请，下一夜再说），且：L 到门档 G（5/10/15）；该档**一次过 ≥2 回合**（`atG≥2`，只数 pass——杜绝"一到就考"，也不会把总在该档点偏的孩子带进注定失败的门）；该门那一行的每个概念标签（照镜子的轴、倒着追、混搭/陌生访客）各有 **≥3 个无帮助通过**；不在冷却 |
| 星门 | 独立事件，不占 6 回合：最多 5 局，档 G−1, G, G−1, G, G；**4 局 pass 开门**；**第 2 个 miss 即止**（一道门最多让孩子点偏 2 回合）；规则同常规回合（含免费第一眼），没有提示/演示/看答案 |
| 没开 | `L=G−1`、`atG` 清零、先来演示回合；回到 G 再一次过 ≥2 回合才再邀请。**连续 2 次**没开 → 冷却 30 个常规回合（再失败 60、120…），期间照常练习；开门后清零 |
| 开门之后（v1.2）| `L=min(下一道门档, G+1)`（门已证明 G−1 与 G），并有「快爬」：接下来 **3 次一次过各升 1 档**，第一个没过就收；之后回到 4 升 1 降。强孩子第一夜：D3、D5、D5、星门、D6、D7、D8（v1.1：D3 之后连玩 5 回合 D5，下一夜才见星门，门后再 4 回合 D5） |
| 机翼 | s2/s4 两翼（D1–10、D11–15），各自 L 与星门（相对档 5/10 与 5）；第 2 翼在第 1 翼开了相对档 5 的门后亮起；**一夜一翼**，下一晚换；整翼精通后每 4 次才轮到一次 |
| 开启 / 推荐 | 上一个星区的 L 首次到 4 就亮下一个（记星星→追流星→送回家→照镜子）。`recommend()`＝最久没玩的已开星区；上一晚是**坏夜**（≥3 次没过）的星区，等别的星区玩满 3 夜再推荐（连续第 2 个坏夜 6 夜、第 3 个 12 夜），连续 3 个坏夜家长页亮提示；孩子仍可点任何节点 |
| 有效夜航 / 回来 | 6 回合里 ≥4 个没点"看答案"才算一个夜航（卡的夜航数用它，§8）；距上次 >14 天：第一回合轻松回合 |

**为什么这样**：4 升 1 降稳态首试通过≈0.841，坏夜实测最高 3.9%（§11.2）；星门要资格与冷却，否则不够格的孩子会在"差一点"的档上无限重考。
**概念准备**：镜像/倒序是**类别性**概念，不是"多一个槽位"。①每种轴前 3 回合是引导；②星门要求相关概念各 ≥3 个无帮助通过；③冷却 + 推荐避让 + 坏夜提示，保证"某条规则怎么也不会"的孩子不掉进星门死循环、不被一晚晚推回去，且在别的星区照常前进（`blind4`，§11.4）；④**开工前 10 分钟探针**：爸爸和小步步玩 3 个左右 + 3 个上下镜像（带演示），做对 <2/3 → 照镜子先不开（节点保持暗星，v1.1 重做引导）。

## 6. 生成器与拒收规则（`gen.mjs`，纯函数 `generate(sector, D, rng, hist)`；尝试上限 4000）
- **s1**：n 分成 k 份逐团摆放（种子格不挨别的团，4/8 邻域随机生长）。**拒收**：团数≠k；密度>40%；与 7 种对称之一重合；n≥4 且共线；与近 W 局**完全相同**；与近 6 局**同形**（旋转/镜像后相同）。旧"围绕同一中心"的缺陷用**格位分布与均匀参考采样器的距离**检验。
- **s2**：最佳候选法撒 m 个点（间距 ≥0.2 板边）；按 exp(−距离/τ)（τ=0.18/0.35/2 对应 c0/c1/c2）加权游走。tangle＝交叉数 + 0.5×急转弯(>120°) + 0.5×[平均步长>0.5]。**拒收**：路线类不符；L≥3 且 x 或 y 单调；**"下一颗＝最近未点星"占比 >0.5，或"只记第一颗、然后总点最近的星"的机器人能过（L≥3）**——评审实测这条捷径在 7 个档上能过 43–94%；c0 只用于 L≤3，**路线类不随 L 升高回落**；重复。倒着追的目标＝展示序列的逆序。
- **s3**：住户身份互异；双胞胎＝共享颜色或形状的住户对，**数量精确**且不相邻；混搭访客＝特征都来自住户、组合不在其中；陌生访客＝两种特征都没出现过。
- **s4**：随机取轴和侧；星星只在源半盘，用 s1 的成团生长（团数 1–2，n≥5 时 1–3）。**拒收**：团数不符；源半盘密度 >50%；n≥3 且共线或包围盒 <2×2；**"搬过去"的答案与正确答案差 <2 格，或"翻错方向/转半圈"的答案与正确答案相同**；同形重复。
- **不重复窗口** W = min(64, ⌊有效池/3⌋)（碰撞数估计；s1、s4 小盘档用 `pool.mjs` **精确枚举核对**）：s1 D1–D5 池 112/352/736/1720/1128；s4 D1–D5 池 32/48/48/96/224（W = 9/12/12/25/53），D6 起 ≥656。页面存每星区最近 64 个精确哈希 + 6 个同形哈希。
- **生成永不抛错**（评审重大项）：`generateSafe`：正常 → 去掉同形窗口 → 去掉全部历史 → 取 `levels.json` 里预算好的**安全题**（60 个，每 (星区,档) 一个）→ 沿用上一个有效题；兜底写日志；`selftest` 注入不可能的行验证零抛错。随机全走 `kit/rng`；`levels.json` 是页面与校验器共用的数据。

**星级按尝试次数**（对象是档位）：某档**第一次被点亮**时，该档第 1 次出现就通过 = 3★，第 2 次 = 2★，第 3 次起 = 1★；用了免费一眼 −1★，用了第二眼或提示再 −1★（最低 1★）。"出现"＝该档的一个回合（含 miss）。**点亮后星数固定，不能刷**。练习回合：带标的档（孩子看到的字是「飞过」，家长页叫桥）**首次一次过（pass）**才按 3★ 计；带帮助或演示的练习（neutral）、没过的练习只有光和音阶，不点亮（v1.2）。**没有速度星和分数。** 策略一句话（`s1.cluster`、`s1.words`、`s3.tip`）每种最多每 3 夜 1 次，不在刚点偏时说（v1.2 接线：第 2 夜起，每夜第 2 回合的提示后）。**新规则自动演示**（v1.2，`Plan.newRuleTag`）：访客（陌生/混搭）、上下镜像、倒着追、记着照**第一次出现**时，回合前先放一遍领航员的幽灵手演示（`s3.visit` / `s4.ex.UD`；挂 kit 跳过，家长开关直接跳），再在新种子上自己做；看过的规则记在 `save.seenRules`。其余接线：`fb.mercy`（轻松回合）、`fb.miss2`（没过后，每夜 1 次）、`s4.ex.LR/UD`（每种轴的第 1 个引导）、`st.bridge` / `sec.s1-4`（进星区页）、`card.*`（新卡大图出现时）。
