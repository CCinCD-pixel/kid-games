# 拼音电台 · 本地验收版

先双击同目录的「启动拼音电台.command」，保持终端窗口打开，再访问终端中给出的地址。默认带 `?mute`，Mac 不会外放。关闭时在终端按 Ctrl-C。不要直接双击 HTML，也不要把源码推送到 GitHub。

完整练习版已包含：读词找图、看图拼搭、听辨、拼合、跟读录音、连词成句、会话复习、卡册及共享 PIN 家长页。内容围绕试卷和拼音能力，不强行逐页对齐教材；需要补练的纯拼音词可在家长页录入。

目前腾讯实际返回“账号未开通本服务”。不开通也能做确定性练习和本机跟读录音；开通后在家长页允许腾讯评测并输入家庭口令。现有账号只用于本机签名，没有创建子账号。口令文件路径由启动终端给出，口令不要贴进代码或聊天。

孩子端没有分数、红叉、倒计时或批评。每题最多三次尝试后看示范，并在后面再练；AI 和孩子自评不计入掌握。

交付目录中的 `app/` 已构建好，无需 npm 安装。`截图/` 展示五种尺寸；`验收报告.md` 记录测试结果与尚待实测的部分；`拼音电台-源码.zip` 是对应本地提交的完整源码，不含 Git 历史。版本见 `VERSION.txt`，文件校验值见 `SHA256SUMS.txt`。

## 建议验收顺序

1. 用默认静音地址查看首页、开始一套节目，点错几次体验提示和示范。
2. 在适合发声的设备和时间，使用不带 `?mute` 的地址试听真人音节和词句。开发全过程未外放试听，尤其请核对 o、ü、轻声和图画能否直接看懂。
3. 进入家长页设置 4–6 位 PIN，查看当前课、拼搭帮助，录入一个拼音城堡练习词；自动拼音可手改。
4. 第一次录音允许麦克风。拒绝权限、断网或腾讯不可用时可继续跟读。回到家长页回听并改判，改判不会重复累计次数。
5. 等待首次资源缓存完成后关闭网络，重新进入并练习。录音与图片只留在本设备，清除站点数据会一起删除。

## iPad 真机

Mac 的 localhost 地址不能直接给 iPad 用；iPad 麦克风要求 HTTPS。可用现有 Tailscale Serve 临时把本机 4188 端口提供给 iPad，设置 PINYIN_ORIGIN 为它的完整 HTTPS origin 后再启动。请按自己的 Tailscale 设备名称操作；本次没有更改现有 Tailscale 配置，没有公开发布。

自动化 WebKit 的 iPad 尺寸测试不等于 iPadOS 26 真机验证。仍须确认主屏 App 权限、录音指示、回听音量和真实评测延迟。
