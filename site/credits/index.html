素材与致谢

星港里用到的字体、音效、语音和图像都来自开放许可或是为这个项目原创的。谢谢这些作者。

字体

霞鹜文楷 GB（LXGW WenKai GB）
作者 落霞孤鹜 LXGW · github.com/lxgw/LxgwWenkaiGB · SIL Open Font License 1.1。阅读和对话文字。按《通用规范汉字表》一级字等常用字子集化，供网页使用（许可全文）。
站酷快乐体（ZCOOL KuaiLe）
站酷 ZCOOL · Google Fonts · SIL Open Font License 1.1。大标题（许可全文）。
Baloo 2
Ek Type · Google Fonts · SIL Open Font License 1.1。数字（许可全文）。

音效

Kenney（kenney.nl）
Interface Sounds、Impact Sounds、Casino Audio、Music Jingles、Digital Audio、Sokoban Pack · CC0 1.0（公共领域）。CC0 不要求署名，我们仍然感谢 Kenney。
原创合成音效
五声音阶的木琴和铃声反馈、伙伴机器人的“嘀嘀”声、飞船发射声等 25 个，为星港原创（CC0）。

语音

Qwen3-TTS（0.6B CustomVoice，mlx-community 8-bit 版）
阿里巴巴通义千问团队 · Apache License 2.0。在这台电脑上本地生成旁白和伙伴机器人的声音，不上传任何内容。
Paraformer 中文语音识别（sherpa-onnx）
仅用于生成后的自动质检（听一遍有没有读错），不随游戏发布。

图像与程序

星港设计系统
剪纸夜空的星港、纸张纹理、43 个界面图标、13 枚游戏徽章、伙伴机器人“领航员”都由代码生成，为这个项目原创。
月相
大厅里的月亮按 Jean Meeus《Astronomical Algorithms》第 48 章的公式在 iPad 上实时计算，不联网。
第一批五款游戏
星港搬运工、星晶消消乐、陆战棋、贪吃蛇大作战、机关守城的画面全部由代码画出；它们的音乐和大部分音效也是为星港原创合成的（CC0）。星港搬运工和星晶消消乐另外用了十几个 Kenney 的 CC0 音效。机关守城为“弩、蒺藜、礌、牒”等字补了霞鹜文楷和站酷快乐体的小子集（SIL OFL 1.1）。
常用字表
《通用规范汉字表》（2013）一级字表，用于决定字体里放哪些字。
